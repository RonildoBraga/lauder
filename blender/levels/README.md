# Levels

These are preserved bridge-authoring sources. The active graybox duel creates its scenery in Swift and loads none of these exports. Saving in Blender keeps the [reference exports](../reference-exports/README.md) current; **Play** launches the current duel, not this historical bridge. The [checkpoint record](../../docs/milestones/bridge-prototype.md) explains how to run the bridge version.

Each Blender file here is a level's source ([ADR 0002](../../docs/decisions/0002-blender-source-of-truth.md)). [Editing a level in Blender](../../CONTRIBUTING.md#editing-a-level-in-blender) describes the retained authoring tools.

## brooklyn-bridge.blend

The Brooklyn Bridge, the opening's level, buried in snow as the frozen [visual direction](../../docs/visual-direction.md) has it. The low-poly environment pass of 23 November 2026 follows the [selected gameplay concept](../../art/bridge/bridge-gameplay-v1.png): twin pointed arches, chamfered stone piers with weathered bases and snow-coloured tops, thin dark cable fans and broad, low snow facets beside the route. Thin flagged poles still mark both edges of the buried road every 25 m, and an invisible edge keeps the party on its line.

The original environment pass preserved the six tower collision boxes, markers, encounter areas, route, camera and lights. The maintainer subsequently selected camera B: offset `[0, 56, 44]` in game coordinates and vertical field of view 22°. The camera changes in Blender and the layout export. The snow drifts stay outside the walkable width and add no terrain or cover. Each tower's cable fans fade with that tower when it hides the party. The masonry's long shadows are baked into the snow; thin cables have no baked or runtime shadow. The current opening starts the three together and has only the first-tower C guard fight; the old recruitment and knife-attacker scenes are removed.

- **Made** for Lauder on 19 November 2026, by the Lauder extension's Load, from the hand-kept layout and palette files that it replaces. Codex authored the environment pass directly in Blender through MCP on 23 November 2026. It has linked no exported [models](../assets/README.md) since the snow buried its vehicles on 20 November 2026; linked party models remain preview-only. It holds no third-party assets or textures.
- **Licence:** the repository's MIT licence.
- **Size:** about 130 KiB, stored with Git LFS. A copy without its payload is a small pointer file; run `git lfs pull`.
- **Exports:** `blender/reference-exports/BrooklynBridge.usdz`, about 46 KiB, and `blender/reference-exports/BrooklynBridgeLayout.swift`. Saving queues the standard background exporter; `blender/level-exports.json` records the fingerprints of both and of the level file.
- **Current visual budget:** 22 mesh objects, 2,804 triangles, six materials and 39 used object/material partitions in the whole exported scene. The original environment pass had 19 meshes and 2,724 triangles, before the supply case and two cover blocks. The runtime layout retains two suns, one casting shadows. Partitions are an authoring measure, not measured GPU draw calls or a phone performance result.

The C integration adds one nonblocking `bridge-supply-case` Visual mesh at game coordinates `[-8.5, -8]`, its `supply.case` marker, an outgoing west-side search area and `robot.exit` area. Tom's spawn marker moves to `[2, -3]` for the case/ambush framing. The six tower blockers, ground, camera B and lights are unchanged. The C guard is spawned by gameplay from its own model export, so it is not duplicated as bridge scenery.

The [27 November cover pass](../../docs/bridge-cover-spacing.md) adds `bridge-cover-west` and `bridge-cover-east` on the approach side of the guard. Each is a simple gameplay box with a matching stone-sided, snow-topped Visual child, using the existing materials. Their positions leave a 2.1 m centre passage and a 3.05 m east flank; the quiet west bypass and the six tower boxes remain unchanged. They add no texture, light, camera change or tower-fade tag. The gameplay checks must establish actual two-muzzle shelter and accessible separate return positions before treating the layout as verified.

The 28 November clean-up ([#227](https://github.com/RonildoBraga/lauder/issues/227)) removes six markers that nothing in the game has read since the 26 November removals: `spawn.tom`, `spawn.laura`, `stranger.hidden`, `attacker.hidden`, `attacker.stand` and `supply.case`. The supply case's Visual mesh and the search area stay. Tom's and Laura's Preview models now stand beside Miki's marker, in the Close formation's places where the game starts them. The exported scene keeps the same 64 prims and values, written in a different order.
