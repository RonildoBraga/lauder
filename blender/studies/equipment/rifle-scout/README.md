# Scout rifle study

**Source:** Original geometry authored for Lauder by Codex, extracted from the Miki angular study at `7d0e79b`. No third-party mesh, texture or animation. **Licence:** Project [MIT licence](../../../../LICENSE).

Open `rifle-scout.blend` to edit its `rifle-scout` collection. This independent, unregistered asset contains **12 mesh parts, 280 triangles, 164 vertices and four matte materials**, about **0.900 m** long. It has no external libraries, character geometry, rig, animation or runtime export.

Native axes are **+Y towards the muzzle, Z up**. The assembly origin and stock, trigger, support, scope and muzzle markers belong to this file. `equipment_interface` identifies the shared stock/grip convention; `equipment_contact_mesh_role` identifies the relevant surface. Preserve or deliberately recheck these references when changing geometry.

The compact optic, narrow fore-end and shorter barrel explore a lighter sniper rifle. Handling and balance remain proposals. This variant has not been fitted or animated on Miki. The [review composition](../../miki-angular/README.md) links it into the rifle-family comparison; placement belongs there. See the [equipment workflow](../README.md).
