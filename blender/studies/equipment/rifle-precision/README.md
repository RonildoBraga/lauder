# Precision rifle study

**Source:** Original geometry authored for Lauder by Codex, extracted from the Miki angular study at `7d0e79b`. No third-party mesh, texture or animation. **Licence:** Project [MIT licence](../../../../LICENSE).

Open `rifle-precision.blend` to edit its `rifle-precision` collection. This independent, unregistered asset contains **12 mesh parts, 280 triangles, 164 vertices and four matte materials**, about **1.060 m** long. It has no external libraries, character geometry, rig, animation or runtime export.

Native axes are **+Y towards the muzzle, Z up**. The assembly origin and stock, trigger, support, scope and muzzle markers belong to this file. `equipment_interface` identifies the shared stock/grip convention; `equipment_contact_mesh_role` identifies the relevant surface. Preserve or deliberately recheck these references when changing geometry.

This is the rifle fitted to Miki's four static review poses. Her low-ready hold places the stock against the coat below the collar; it does not demonstrate scoped aim, cheek contact, recoil or draw/stow transitions. The [review composition](../../miki-angular/README.md) owns those placement transforms and references this same source in every view. Handling and balance remain proposals. See the [equipment workflow](../README.md).
